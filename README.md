# Практическая работа 01

**Настройка среды PHP и исследование HTTP-запросов и ответов**

Группа: CS-302(С)

| Параметр | Значение |
|---|---|
| Вариант | A (Кабель — 12500, Чехол — 7500) |
| Версия PHP | 8.3–8.5 (проверено также на 8.2) |
| Адрес запуска | http://localhost:8088/ |
| Веб-корень | `C:/WebLabs/pr01/public` |

## Запуск

1. Скопировать проект в `C:\WebLabs\pr01`.
2. Вариант задаётся в `config.php`.
3. Подключить `apache-course.conf` в Uniform Server (VirtualHost на `public`, порт 8088, `AllowOverride All`).
4. Открыть `http://localhost:8088/health.php` — `stage: 1`, версия PHP, SAPI веб-сервера.

Альтернатива без Apache:

```
php -S localhost:8088 -t public router.php
```

Проверка синтаксиса:

```
php -l app.php
php -l public/index.php
```

## Выполненные TODO (`app.php`)

- `P01-GET` — `getQuantities()` читает `qty_first` и `qty_second` из переданного `$_GET` и проверяет их через `quantity()`.
- `P01-POST` — `postQuantities()` делает то же для `$_POST`.
- `P01-SUM` — `totalMinor()` берёт серверные цены из `prices()` (индексы 1 и 3) и считает сумму в целых минимальных единицах.
- `P01-HEADER` — `practiceHeader()` устанавливает `X-Practice: 01`.

Сумма считается в целых числах до форматирования, поэтому не возникает ошибок округления `float`; деление на 100 выполняется только при выводе.

## Статусы и граничные значения

| Сценарий | Результат |
|---|---|
| GET и POST, 2 и 1 | 200, 325.00 |
| 0 и 0 | 200, 0.00 |
| Нет второго поля | 400 |
| Пустое поле, -1, 100, 2.5, abc, 02 | 400 |
| Массив `qty_first[]=2` | 400, без TypeError |
| GET к /preview | 405, `Allow: POST` |
| POST к /quote | 405, `Allow: GET, HEAD` |
| /missing | 404 |
| HEAD к /quote | 200, те же заголовки, без тела |
| POST /preview?qty_first=99&qty_second=99 с телом 2 и 1 | 200, 325.00 — данные берутся из тела |

## Ответы на вопросы

1. **Браузер и сервер.** Браузер формирует запрос и отображает HTML. Сервер выполняет PHP: читает и проверяет параметры, считает сумму по серверным ценам, формирует статус, заголовки и тело ответа.
2. **Метод и статус.** Метод (GET, POST, HEAD) — часть запроса, действие клиента. Статус (200, 400, 404, 405) — часть ответа, результат обработки.
3. **Параметры URL у POST.** Строка запроса и тело — разные части запроса: строка запроса доступна через `$_GET` при любом методе, тело формы — через `$_POST`.
4. **Проверка HTML-поля.** Атрибуты `min`, `max`, `required` работают только в браузере и обходятся через curl, поэтому сервер проверяет данные сам в `quantity()`.
5. **405 и Allow.** Ресурс существует, но не поддерживает этот метод; `Allow` перечисляет разрешённые методы.
