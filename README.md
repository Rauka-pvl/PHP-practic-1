# Практическая работа 01

**Настройка среды PHP и исследование HTTP-запросов и ответов**

Группа: CS-302(С)

## Параметры

| Параметр | Значение |
|---|---|
| Вариант | A (Кабель — 12500, Чехол — 7500) |
| Версия PHP | 8.2+ (рекомендуется 8.3–8.5) |
| Адрес запуска | http://localhost:8088/ |
| Веб-корень | `pr01/public` |

## Структура

```
app.php            функции чтения параметров, расчёта, заголовка и HTML-обёртки
config.php         выбор варианта A/B/C и серверные цены
stage.php          номер и название работы
router.php         маршрутизатор для встроенного сервера PHP
public/index.php   выбор сценария по URL и методу
public/health.php  проверка окружения
public/.htaccess   передача /quote и /preview в index.php
public/style.css   оформление
```

## Запуск

Apache (Uniform Server): веб-корень `C:/WebLabs/pr01/public`, порт `8088`, включены `mod_rewrite` и `AllowOverride All`.

Встроенный сервер PHP (альтернатива):

```
php -S localhost:8088 -t public router.php
```

Проверка синтаксиса:

```
php -l app.php
php -l public/index.php
```

## Результаты трёх проверок

**1. GET с количествами 2 и 1**

```
curl.exe -i "http://localhost:8088/quote?qty_first=2&qty_second=1"

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
X-Practice: 01
...Итого 325.00
```

**2. POST с количествами 2 и 1**

```
curl.exe -i -d "qty_first=2&qty_second=1" "http://localhost:8088/preview"

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
X-Practice: 01
...Итого 325.00
...Это только предпросмотр: заказ не сохраняется и никуда не отправляется.
```

**3. GET к /preview (неподходящий метод)**

```
curl.exe -i "http://localhost:8088/preview"

HTTP/1.1 405 Method Not Allowed
Content-Type: text/html; charset=UTF-8
X-Practice: 01
Allow: POST
```

## Статусы и граничные значения

| Сценарий | Результат |
|---|---|
| GET и POST, 2 и 1 | 200, 325.00 |
| 0 и 0 | 200, 0.00 |
| Нет второго поля | 400, «Поле qty_second отсутствует в запросе.» |
| Пустое поле, -1, 100, 2.5, abc, 02, +1 | 400 |
| Массив `qty_first[]=2` | 400, без TypeError |
| GET к /preview | 405, `Allow: POST` |
| POST к /quote | 405, `Allow: GET, HEAD` |
| /missing | 404 |
| HEAD к /quote | 200, те же заголовки, тело отсутствует |
| Конфликт: POST /preview?qty_first=99&qty_second=99 с телом 2 и 1 | 200, 325.00 (данные берутся из тела) |

## Ответы на вопросы

1. **Браузер и сервер.** Браузер формирует HTTP-запрос (метод, URL, тело формы) и отображает полученный HTML. Сервер выполняет PHP: читает параметры, проверяет их, считает сумму по серверным ценам и формирует ответ со статусом и заголовками.
2. **Метод и статус.** Метод (GET, POST, HEAD) — часть запроса, описывает действие клиента. Статус (200, 400, 404, 405) — часть ответа, описывает результат обработки на сервере.
3. **Параметры URL у POST.** URL и тело — разные части запроса. Строка запроса доступна через `$_GET` при любом методе, тело формы — через `$_POST`.
4. **Проверка HTML-поля.** Атрибуты `min`, `max`, `required` работают только в браузере и легко обходятся через curl или инструменты разработчика, поэтому сервер обязан проверять данные сам в `quantity()`.
5. **Ответ 405 и Allow.** 405 означает, что ресурс существует, но не поддерживает использованный метод. Заголовок `Allow` сообщает клиенту, какие методы разрешены.
